# Seed catalog

24 products across 6 categories. Copy each block into **Seller → New product**.

**Before you start:** the product schema has **no category field**. Categories
below are for *your* organisation and for choosing coherent photography — they
are not stored and cannot be filtered on. Search matches title and description
only, so each description deliberately contains the words a buyer would type.

Descriptions are all under the backend's 500-character limit. Prices are in
rupees. Currency is INR.

## Photography direction

All 24 shots must share one setup or the catalog will look like a scrape:

```
Seamless warm bone backdrop, hex #f5f3ee. Soft diffused light from the
upper left. Subtle contact shadow. 50mm, product centred, square 1:1.
No text, no props, no hands, no watermark.
```

The backdrop colour is the site's canvas colour, so products sit *on* the page
rather than floating in a white box.

**Sources, in order of preference:** the manufacturer's own press images (most
of these brands publish them), then Unsplash, then AI generation. Real product
photography of real products always beats a generated approximation, and every
item above was chosen because good images of it exist.

Upload up to 5 per product. The first image is the one the catalog grid shows,
so make it the straight-on shot.
